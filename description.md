# Как работает генератор

- В `generateValueOfType` передаём `Class<?>` нужного типа и получаем сгенерированное значение.
- Для примитивов, обёрток и строк используем `Random`. У `enum` выбираем случайную константу.
- Для объектов перебираем публичные конструкторы. Аргументы генерируем рекурсивно, возвращаем результат первого успешного вызова.
- Массивы заполняем поэлементно, в том числе вложенные. Для `List` создаём `ArrayList`, для `Map` - `HashMap`.
- Если объект создать не получилось, выбрасываем `GenerationException`. Ошибки отдельных попыток сохраняем через `addSuppressed`.

# Аннотация @Generatable

- В [Generatable.java](src/main/java/org/example/annotation/Generatable.java) указываем `subtypes` - классы, которые могут быть созданы вместо текущего.
Базовый сценарий применения: у интерфейса указываем классы, которые его реализуют.
- Для обычного класса сначала пробуем создать его самого. Если все конструкторы не подошли - пробуем подтипы.
Для интерфейсов и абстрактных классов также используем указанные подтипы, так как создать сам тип нельзя.
- Подтипы перебираем в порядке из аннотации. Несовместимые типы пропускаем, возвращаем первый успешно созданный объект.

# Существующие ограничения и условности

- Максимальная глубина рекурсии - 10, начальная - 0. Начиная с глубины 10 для ссылочных типов возвращаем `null`, примитивы продолжаем генерировать.
- Длина строк и массивов - от 0 до 19. Размер списка - от 1 до 20. Для `Map` генерируем от 1 до 20 пар
- `int` и `long` генерируем без дополнительных ограничений. `byte` - от 0 до 127, `short` - от 0 до 31999,
`char` - от 0 до 65534, `float` и `double` - от 0 включительно до 1 не включительно. Строки могут содержать непечатные символы.
- Коллекции поддерживаем с известными типами в параметрах конструктора, например `List<Product>` и `Map<String, Integer>`.
- Предметные ограничения не проверяем: например, сгенерированные стороны треугольника могут не задавать существующий треугольник.
